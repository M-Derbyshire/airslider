# [IHitBox](../../Kernel/entities/Model/IModel.ts)

Coordinates and dimensions for a model's hit box. A hit box will surround a part of the model, and can be used in events (such as collision detection). Multiple boxes could be used to cover the actual shape of the model's sprite.

## Properties:

### `x`

The x position (in units) of the box

### `y`

The y position (in units) of the box

### `z`

The z position (in units) of the box

### `width`

The width (in units) of the box

### `height`

The height (in units) of the box
