# TimeHelper

Contains methods that provide information related to time

## Static Methods

### `secondsToFrames`

Calculates the amount of frames that will be rendered during a given amount of seconds (as this is based on a dynamic FPS, the returned value can only be considered an estimate).

#### Parameters:
- **seconds** - the amount of seconds

### `minutesToFrames`

Calculates the amount of frames that will be rendered during a given amount of minutes (as this is based on a dynamic FPS, the returned value can only be considered an estimate).

#### Parameters:
- **minutes** - the amount of minutes
