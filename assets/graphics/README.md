# Graphics

These files relate to the game's graphics.

Some of these are old ideas that never ended up being used (some of the monsters, for example). Not all of the game's graphics can be found in this directory -- some of them now only exist alongside the code.

Most of the images were created with Paint.NET (an open-source image editing application). The _.pdn_ files can be opened with Paint.NET (or LazPaint, if you're not using Windows). Some of the images were created with LazPaint (these are the _.lzp_ files). The "spritesheet" files are the ones used by the game's models.
