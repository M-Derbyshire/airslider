# Music

The music in the game was created with an old version of Garageband, on an old IPad. The music was then looped with Audacity.

For each track in the game, there are 4 items:
- _.band_ directory -- This contains all the project data from Garageband
- _.aif_ file -- This is the full-quality music file
- _.aup3_ file -- This is the Audacity file, that was used to loop the music
- _.mp3_ file -- This is the music file that will be used in the game
